# Task 2 - Machine Learning Model

## 📌 Project Overview
This project builds machine learning models to predict annual salary based on experience level and job category.

## 🔧 Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## 📊 Evaluation
Models were compared using R² Score to measure performance.

## 🔍 Key Insights
- Random Forest performed better compared to other models
- Salary increases with experience level
- Job category impacts salary prediction

## 🛠️ Tools & Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
